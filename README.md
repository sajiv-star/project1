
The Retail POS System is a Java-based application designed to manage retail store operations efficiently. It allows users to add products, manage suppliers, and track inventory. The system supports creating purchase orders and receiving purchased products. It processes sales and generates bills with automatic tax calculations. It provides bulk discounts when customers purchase ten or more units of a product in a single sale line. The application updates stock levels automatically after purchases and sales. It validates user inputs and handles errors to ensure reliable operations. The project uses Object-Oriented Programming concepts such as inheritance, encapsulation, abstraction, and polymorphism. Java Collections are used to manage products, suppliers, and orders. The application provides a simple menu-driven interface for users. It is developed using Java and can be executed in Eclipse IDE. This project demonstrates practical Java programming skills and retail inventory management concepts.
